# 기능 명세서

의료 영상 학습 앱. 로그인 후 부위·영상 종류에 맞는 문제를 풀고, ROI를 그려 제출한 뒤 채점 결과를 본다. `[x]`는 지금 코드에 있는 동작, `[ ]`는 아직 구현할 동작이다.

## 공통

- [x] `/` 는 세션이 있으면 `/medical?region=brain&type=CT`, 없으면 `/login`
- [x] 헤더에 부위·영상 종류·"문제 풀이"를 표시한다
- [x] 로그인 사용자는 헤더에서 이름을 보고 로그아웃할 수 있다
- [x] 로그아웃은 `medlens_user`와 `medlens.review`를 지우고 `/login`으로 간다
- [x] `/medical`, `/medical/review`, `/main` 는 세션이 없으면 `/login`으로 보낸다
- [x] 헤더 "가이드"는 원/박스 드래그, 제출, 리뷰 순서를 패널로 보여 준다

## 메인 홈 `/main`

- [x] 세션 이름으로 "안녕하세요, {이름}님"을 보여 준다
- [x] "학습하기"와 "학습 시작"은 `/medical?region=brain&type=CT`로 이동한다
- [x] 헤더에 MedLens, 학습, 오답노트, 마이페이지를 보여 준다
- [x] 오늘의 학습 현황을 부위별로 보여 주고, 오늘 학습한 부위만 표시한다
- [x] 부위마다 학습 시간·학습 문제·정답률을 보여 준다
- [ ] 오답노트·마이페이지·학습 기록 화면으로 이동한다
- [ ] 오늘의 학습 현황을 서버 값으로 채운다

## 로그인 `/login`

- [x] 아이디, 비밀번호를 입력한다
- [x] `POST http://127.0.0.1:8000/login` 본문 `{ userId, userPw }`
- [x] 성공(`ok`) 시 세션을 저장하고 풀이 화면으로 이동한다
- [x] 실패 시 서버 `detail` 또는 `message`, 없으면 "아이디 또는 비밀번호가 올바르지 않습니다."
- [x] 이미 로그인된 사용자는 풀이 화면으로 보낸다
- [x] 가입 화면으로 이동하는 링크가 있다

## 회원가입 `/signup`

- [x] 1단계: 아이디/이메일, 비밀번호, 비밀번호 확인
- [x] 2단계: 이름(최대 5자), 생년월일, 학교, 전공
- [ ] 1단계에서 필수값 누락과 비밀번호 불일치를 막는다
- [ ] 2단계에서 가입 API를 호출하고, 성공하면 로그인 화면으로 보낸다
- [ ] "가입 완료"가 1단계로 되돌아가지 않는다

## 문제 풀이 `/medical`

- [x] `GET /learning/problem` 으로 문제와 영상 경로를 불러온다
- [x] 영상은 이미지 서버 기준 경로로 표시하고, 로딩·오류 문구를 보여 준다
- [x] `type=MRI` 이고 `st_image`가 경로 배열이면 슬라이더·휠로 슬라이스를 넘긴다. CT 등은 한 장만 쓴다
- [x] MRI 슬라이스는 받은 장을 캐시하고 근처 장을 미리 받아 스크롤을 부드럽게 한다
- [x] ROI 도구: 원, 박스, 지우기. 드래그로 영역을 추가한다
- [x] 제출은 `POST /learning/roi-grade`. 여러 ROI면 마지막 영역으로 채점한다
- [x] MRI 제출은 `slice_index`(0-based)와 `image_path`를 함께 보내고, CT는 기존처럼 생략한다
- [x] 채점 결과와 사용자 ROI·슬라이스 정보를 `medlens.review`에 저장하고 `/medical/review`로 이동한다
- [x] 오른쪽 용어 사전은 `GET /glossary` 결과를 보여 준다
- [x] ROI가 하나도 없으면 제출하지 않고 "ROI를 하나 이상 지정해 주세요."를 보여 준다

## 채점 리뷰 `/medical/review`

- [x] 저장된 영상, 사용자 ROI, 오버레이, 판정(정답/부분정답/그 외)을 보여 준다
- [x] MRI면 제출한 슬라이스 번호(예: 슬라이스 43 / 190)를 결과·요약에 보여 준다
- [x] 저장값이 없으면 화면용 기본 채점 데이터를 쓰고, 목업임을 표시한다
- [x] "다음 문제"는 같은 `region`, `type`으로 `/medical`에 돌아간다
- [x] "학습 종료"는 풀이 화면이 아니라 `/main`(로그인 유지 홈)으로 보낸다
